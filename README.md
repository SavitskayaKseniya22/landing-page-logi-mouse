# [Logi mouse](https://landing-page-logi-mouse.netlify.app/)
Logitech mouse advertising landing page

## Features
- Mobile-layout
- Burger-menu
- Carousel-surfaces

## Tech Stack
- Bootstrap-carousel
- Eslint
- Prettier
- Sass
- Vite
- Normalize.css

## How to use
1. Clone the repo
``` bash
git clone https://github.com/SavitskayaKseniya22/landing-page-logi-mouse.git
```

2. Install dependencies
``` bash
npm install
```

3. Start the Vite dev server
``` bash
npm run dev
```
